# Chunk 合并功能测试用例

## 测试环境
- 基础URL: http://localhost:8000
- 测试页面: /chunks.html
- 浏览器: Chromium

## 测试前置条件
1. 后端服务已启动（uvicorn src.aitechpioneer.interfaces.api:app --host 0.0.0.0 --port 8000）
2. 数据库中至少有一个文档及其对应的chunks
3. 测试数据准备：至少有3个以上的chunk用于测试合并功能

## 测试用例 2: 选择两个Chunk进行合并

**测试ID**: TC002
**测试名称**: 选择两个Chunk并合并
**优先级**: 高
**测试类型**: 功能测试

**前置条件**:
- 页面已加载chunk列表
- 至少有2个chunk可供选择

**测试步骤**:
1. 在chunk列表中找到第一个chunk
2. 点击第一个chunk的复选框
3. 点击第二个chunk的复选框
4. 点击"合并选中"按钮
5. 在弹出的合并预览对话框中确认合并
6. 等待合并完成

**预期结果**:
- 只能选择最多2个chunk
- 合并按钮在选择2个chunk后变为可用状态
- 弹出合并预览对话框，显示两个chunk的内容和合并后的内容
- 确认后显示合并成功提示，包含新的chunk ID
- chunk列表刷新，显示新的合并后的chunk
- 原始的两个chunk被标记为MERGED状态

**实际结果**: (待测试)
